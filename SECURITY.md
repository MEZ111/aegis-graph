# Security policy

Please report vulnerabilities in AegisGraph privately through GitHub's private vulnerability reporting for this repository when available. Do not publish sensitive infrastructure models, live credentials, customer topology, or third-party data in a public issue.

A useful report includes the affected version/commit, a minimal synthetic model, expected behavior, actual behavior, and security impact. AegisGraph is a defensive threat-modeling tool; authorization to test any third-party system remains the tester's responsibility.
